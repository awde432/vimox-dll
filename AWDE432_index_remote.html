02

它到底是什么，以及它不是什么

很多远程软件的问题不在于功能不够，而在于定位模糊。我们把边界写清楚，避免你装完才发现不合适。

一句话定义：ViMoxPC 是运行在 Windows 上的局域网远程控制工具——由「被控端」和「控制端」两部分组成，被控端开放屏幕与操作权限，控制端在另一台电脑上查看并操作它。

  • 它是一套局域网方案。设备通过局域网广播相互发现，连接在本地网络内完成，不依赖公网中转。
  • 它是双向的。任何一台电脑都可以既是控制端、又是被控端，取决于你打开哪个角色；但同一时刻只维持一条连接。
  • 它是桌面级工具。面向的是"人坐在电脑前操作另一台电脑"，不是设备远程唤醒、不是手机端控制、不是云桌面。
  • 它把文件传输做在同一个界面里。不需要另开网盘、FTP 或聊天软件传文件。
  • 它不需要你懂网络配置。不需要端口映射、不需要 DDNS、不需要改路由器。

它不是什么（诚实说明）

ViMoxPC 不是公网远程控制：如果你的两台设备不在同一局域网、也没有任何互通手段，它无法建立连接。

它 不是多路并发工具：一次只能连接一台设备，不存在"多台画面同时铺开"的能力。

它 不是云服务：没有网页控制台，也没有"登录后从任何地方访问"的能力。

它 不是监控软件：没有隐身运行、没有后台抓屏上传、没有"家长控制"式的偷偷记录。被控端在运行中是可见、可退出的。

它 不是手机 App：目前只提供 Windows 桌面端。

核心功能：每一项能为你做什么

下面 10 项功能按"解决什么问题"组织。每项都写清了它能做什么、在什么情况下有用，以及它的能力边界。

功能 01

实时屏幕监控

把被控电脑的屏幕画面实时呈现在你的窗口里，一台一台地看。适合远程排障时先"看清现场"，再决定要不要接管操作。

  • 解决不用走过去，也能知道对方屏幕上是什么
  • 典型用法连接成功后先看画面，确认状态再动手
  • 边界画面以 JPEG 压缩传输，清晰度与流畅度受局域网带宽影响

功能 02

远程操作控制

不只是看，还能直接操控对方的鼠标和键盘：单击、双击、右键、拖拽、滚动，以及组合键与常用快捷键输入。操作手感接近本机，适合远程帮人解决问题、远程演示某个操作步骤。

  • 解决电话里说不清楚的操作，直接替对方做一遍
  • 典型用法远程指导、远程演示、远程排障
  • 边界需要被控端授予控制权限后才能操作

功能 03

双向文件传输

在控制端与被控端之间互传文件：既可以把本地文件推送到对方电脑，也可以把对方电脑上的文件取回本地。走的是同一局域网链路，速度取决于你的网络环境，大文件不必再找 U 盘或中转盘。

  • 解决机房分发资料、回收作业、传大文件
  • 典型用法逐台分发资料 / 逐台回收文件
  • 边界传输目标目录需可写；受剩余空间限制

功能 04

设备自动发现

在同一局域网内，软件会自动把在线设备列出来，你从列表里点一下就能发起连接，不需要手工记 IP、不需要逐个输入地址。设备换 IP、重启后重新上线，也会重新出现在列表里。

  • 解决不用维护一张"哪台机器是哪个 IP"的表格
  • 典型用法新机器接入即被发现，随开随用
  • 边界需在同一网段；部分网络会限制广播

功能 05

设备记录与快速连接

连接过的设备会被记录下来，下次直接从列表里选中即可再次连接，不用重新回忆 IP 与端口。注意：这是"历史记录 + 免输入"，不是多路并发——同一时刻仍然只维持一条连接。

  • 解决重复输入地址、记不住哪台是哪台
  • 典型用法固定几台机器之间来回使用
  • 边界一次只连一台，切换设备需先断开当前连接

功能 06

连接密码验证

发起连接需要校验密码，密码正确后还需要被控端本人确认授权才会真正建立连接。每台设备的连接密码由本机独立生成、保存在本机，开发者服务器不存储你的密码。另外还有"无需密码"模式，但这意味着任何知道你 IP 的人都能向你发起请求，是否被控制取决于你是否点了"允许"，风险请自行判断。

  • 解决防止局域网内其他人随意接入你的电脑
  • 典型用法每台机器独立密码 + 被控端人工确认
  • 边界密码强度由使用者负责；忘记密码可在"设备连接安全"中重设

功能 07

配置持久化

用户名、密码、网络端口、偏好设置等可以保存下来，下次启动直接沿用，不必每次重新填。对需要长期固定部署的机房机器来说，这一步能省掉大量重复劳动。

  • 解决每次启动都要重新配置
  • 典型用法批量部署同一套配置
  • 边界配置保存在本机，重装系统前请注意备份

功能 08

操作日志记录

关键动作会被记录下来，方便回溯"谁在什么时候连过哪台机器、做过什么"。出现问题时可查、可追；在需要交代操作过程的场合，日志就是凭据。

  • 解决事后无从追溯
  • 典型用法运维留痕、教学管理核查
  • 边界日志存放于本地，请自行做好留存与保护

功能 09

紧急断开与断开控制

远程连接期间，被控端随时可以终止连接：点击"断开"按钮，或连续按下两次 ESC+F12，即可立即切断所有远程操作。控制权始终在被控端手里，这一点是刻意设计的。

  • 解决发现被异常连接时，要能立刻切断
  • 典型用法被控端一键/快捷键紧急断开
  • 边界断开后需重新发起连接并再次验证

功能 10

官方安装包分发

软件通过官方安装包分发：从官方渠道取得安装包后，按安装向导完成安装即可使用，无需你自己配置 Python 环境或手动安装依赖。请只使用官方发布的安装包，来源不明的"绿色版""破解版"可能被二次打包。

  • 解决自己配运行环境容易出错
  • 典型用法官方安装包 + 安装向导一步装好
  • 边界需按向导完成安装；请勿使用来源不明的第三方打包版本

为什么用局域网直连，而不是公网中转

公网中转意味着你的画面要经过一台你并不拥有的服务器。局域网直连把这台服务器去掉了：更快，也更少一个需要信任的对象。需要说明的是，程序仍会向开发者云端提交 GitHub 账号数字 ID 用于设备注册与黑名单比对，这是唯一的云端通信。

为什么需要登录账号

登录使用 GitHub OAuth 授权，以你的 GitHub 账号数字 ID 作为身份标识，用于设备注册与黑名单比对。个人资料、已保存的设备记录、设置与连接日志保存在本机数据目录，登录先把这些数据对号入座，避免把甲机器的记录混进乙用户的目录。

为什么坚持原生桌面界面

远程控制是长时间挂着用的工具。原生控件在窗口缩放、输入法等细节上更稳，不会出现"套壳窗口"常见的错位问题。

登录或账号身份验证失败，怎么办？

先看一个前提：如果这台电脑能正常上网（能打开网页、能看视频），但程序登录不上、或提示与证书 / 安全连接有关的错误，那多半不是账号问题，也不是网络问题，而是系统缺少根证书。

为什么会这样。袖珍版、装机版、网吧版、GHOST 版这类被精简过的 Windows，为了压体积，把系统自带的「受信任的根证书颁发机构」列表一并删掉了，同时关闭了根证书自动更新。程序与服务器之间走的是 HTTPS，证书校验通不过，连接就会在登录这一步被打断；账号身份验证走的是同一条通道，所以会一起失败。正常安装的 Windows 自带这套证书，不会遇到这个问题。

怎么解决（三步）。① 以管理员身份打开「命令提示符」或 PowerShell；② 依次执行下面两条命令（需要联网）：
certutil -generateSSTFromWU roots.sst
certutil -addstore -f root roots.sst
第一条从微软服务器下载完整的根证书列表，第二条把它安装进系统；③ 重启 ViMoxPC，重新登录。

若执行完仍无法登录，说明该系统缺失的不止证书一项，建议改用微软官方原版镜像安装的 Windows，或换一台完整版系统的电脑使用。

怎么快速自检。用浏览器打开任意 HTTPS 网站，如果频繁弹出「证书无效」「你的连接不是私密连接」这类警告，基本就能确认是系统根证书缺失。
